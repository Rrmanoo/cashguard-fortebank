# API для жюри

Базовый URL работающего демо указан в README. Ключ передаётся только в заголовке `X-API-Key`; файл с действующим ключом передаётся жюри отдельно. Модельный ключ не требуется. OpenAPI: `/docs`, `/openapi.json`.

```bash
# Введите полученный от команды ключ, не помещая его в историю shell.
read -rs JURY_KEY; export JURY_KEY
curl -sS "$CASHGUARD_URL/api/v1/analyze" \
  -H "X-API-Key: $JURY_KEY" -F 'file=@example.mov;type=video/quicktime'
# HTTP 202: {"job_id":"...","status":"processing"}
curl -sS "$CASHGUARD_URL/api/v1/jobs/JOB_ID" -H "X-API-Key: $JURY_KEY"
```

При `status=done` поля `verdict` и `violations` находятся на верхнем уровне ответа. `verdict`: `violation` либо `no_violation`. Каждое нарушение: `type`, `type_id`, `timecode_sec`, `description`, `evidence_frames` (1–3 объекта `timestamp_sec`, `image_base64`, чистый JPEG base64), `rule` (документ, пункт, URL, характер сопоставления). Дополнительные поля: журнал, неизвестные критерии, время, параметры анализа. При `failed` возвращается `error`; такой результат нельзя считать отрицательной классификацией.

| Ситуация | HTTP / статус |
|---|---|
| Нет ключа или неправильный | 401 |
| Файл не `.mov` | 415 |
| Пустой файл | 400 |
| Больше 128 MiB | 413 |
| Модель недоступна при приёме | 503 |
| Уже обрабатывается видео | 429 + Retry-After |
| Принято | 202 |
| Задание не существует / истекло | 404 |
| Обработка >270 с, повреждённое видео, ошибка модели | задание `failed` |

Браузер после ввода ключа получает HttpOnly/SameSite cookie на 12 часов. Ключ не хранится в localStorage и не включён в JS. Галерея, видеопотоки, правила и результаты требуют авторизации. Без ключа открыт только интерфейс, документация API и healthcheck. `/healthz` проверяет доступность модели, но не гарантирует срок следующего inference.
