Проверочный MOV принят по HTTPS с HTTP 202; GET задания вернул `done` с валидным verdict, типами и JPEG-доказательствами. Время от начала загрузки до получения полного результата: **58.748 с**. Это один отдельный API пример; он не доказывает SLA для всех новых видео.

Структурная проверка всех результатов: **1439 сохранённых вызовов, 410 кадров-доказательств, 40 уникальных результатов**, без несогласованности формул/таймстемпов/байтов JPEG. Семь файлов inference и критериев совпадают с хешами до запуска. Это целостность артефактов, а не подтверждение визуальной истинности ответов. 53 теста кода прошли локально и на CPU.
